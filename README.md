# COVID-19 Data Visualization Dashboard

Интерактивный дашборд для отслеживания динамики распространения коронавируса (COVID-19) по странам и регионам. Проект позволяет анализировать ключевые метрики: количество зараженных, летальных исходов, выздоровевших, а также темпы распространения инфекции.

## 🚀 Возможности

- **Глобальная статистика**: общее количество случаев, смертей, выздоровлений.
- **Динамика по странам**: выбор любой страны или континента.
- **Временные ряды**: графики новых случаев за день, скользящее среднее (7 дней).
- **Карта заболеваемости**: хороплет (тепловая карта мира).
- **Сравнение**: до 5 стран на одном графике.
- **Экспорт данных**: выгрузка текущего графика в PNG/CSV.
- **Автообновление** (опционально): данные подтягиваются из актуального API.

## 🛠 Технологии

- **Язык**: Python 3.9+
- **Библиотеки**:
  - `pandas` — обработка и агрегация данных
  - `plotly` / `matplotlib` — визуализация
  - `dash` (если веб-дашборд) или `streamlit`
  - `requests` — получение данных из API
- **Источники данных**:
  - [CSSE COVID-19 Data (Johns Hopkins)](https://github.com/CSSEGISandData/COVID-19)
  - [Our World in Data](https://github.com/owid/covid-19-data)
